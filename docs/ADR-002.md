# ADR 002: observable evidence and inspectable local video

Date: 7 November 2026. Adopted for offline/local experiments. Real café action
accuracy and production deployment remain unapproved by this decision.

The existing tracking, frame transactions, POS conservation and worker deadlines
are retained. No target-camera evidence justifies replacing them with an end-to-end
video model or adding distributed infrastructure. The cached Apache-2.0 model-card
RT-DETRv2-R18 checkpoint supplies an actual pretrained detector without a new large
download; this is a licensing/integration choice, not a café accuracy ranking.

The legacy detector-worker interface now dispatches an explicit backend. RT-DETR
uses local safetensors, exact native class names/IDs and checkpoint hashes. Raw
proposals remain available for AP; configured acceptance thresholds select inputs
to the tracker. A low-score proposal flood must not masquerade as confirmed people
or make every frame unknown through the legacy low-confidence-person rule.

Preparation and pickup regions extend the existing zone engine. The opt-in product
evidence layer distinguishes initial presence, continuous outside-to-pickup movement,
visible departure, advisory interaction and lost visibility. Gaps reset transfer
evidence. Preparation completion, confirmed handover and customer role remain
unavailable; no cup/dwell/disappearance-to-sale shortcut is adopted.

The optional video path uses source PTS rather than nominal FPS. Its decoder/encoder
queues are bounded, workers have deadlines, exports stream to disk, labeling frames
are capped and telemetry stores aggregates. MP4 timing has a stated 1/60000-second
quantization; audio is omitted and odd dimensions padded. Original source bytes
are unchanged. The legacy CFR/live replay path remains available with its limits.

Foundation traffic extensions use finite directional lines, dwell and continuous
anonymous tracks. Reviews append corrections; business reports apply the latest
decision without rewriting observations. Local-day reports expose gaps/coverage.
An exploratory reporting index was removed after increased write timings without
measured read benefit. Existing indexes and SQLite remain the baseline.

The authenticated HTTP service is restricted to loopback read-only review. Remote
hosting, frontend, long-term retention and multi-camera expansion require separate
evidence and deployment design. Current pinned Torch environments retain advisory
debt; trusted checkpoints and isolation do not establish production security clearance.

Validation: [foundation snapshot](benchmarks/foundation_results.json) and
[current video evidence](benchmarks/video_prototype_results.json). Revisit the model,
tracker, crop strategy or temporal classifier after source-bound independent labels
identify the actual error. Retest exported runtimes against event outcomes before
promotion. Do not infer production capacity or café recognition from software fixtures.
